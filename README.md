# ValidDoc API - Landing Page

Landing page moderna em React + Tailwind para divulgar a API de validação de CPF e CNPJ.

## 🚀 Executar localmente

```bash
npm install
npm run dev
```

## 📦 Deploy

Hospede no Vercel, GitHub Pages (via build), ou outro serviço.
